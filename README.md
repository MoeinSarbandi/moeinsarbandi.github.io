# Moein Sarbandi — Academic Website

This repository contains the source code and content for my academic website:

**https://moeinsarbandi.github.io/**

The site presents my research, publications, student projects, teaching activities, academic service, conference and research gallery, and curriculum vitae.

My research focuses on robust and nonlinear control, sliding-mode control, data-driven control and informativity, observer design, learning-based control, and applications to floating offshore wind turbines.

## Main sections

- About
- Publications
- Projects
- Teaching
- Academic activities
- Gallery
- CV

The website is built with Jekyll and the **al-folio** academic website framework. Theme/runtime files are retained where they are needed for building, deploying, testing, or maintaining the site; example/demo content from the original template is not part of the website content.
